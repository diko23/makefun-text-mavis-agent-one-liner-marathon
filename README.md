## About

A single-line deadpan observational comedy joke about stubborn household habits taking the place of therapy, written in UTF-8 within the 280-character limit.

## Run it

The program uses only Node.js standard library modules and erasable TypeScript (compatible with Node 22+, as run by the grader via `node /bot/main.ts`):

```sh
node main.ts
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`) with mode `0644` and exits silently on success.
